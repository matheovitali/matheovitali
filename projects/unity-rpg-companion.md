# Unity tabletop RPG companion

[Back to my profile](../README.md)

I'm working on a 2D companion app for tabletop RPG sessions, using Unity 6 and C#. The idea is to bring session tools, shared interactions and persistent data into one application.

## What I'm building with

- Unity and C# for the application and interface
- Netcode for GameObjects for multiplayer state
- Firebase/Cloud Firestore for stored data
- NUnit for automated tests

One of the trickier parts is deciding what should stay local to each player and what needs to be synchronized. I'm also working on keeping data access and UI logic separate enough to test and change them independently.

This is an ongoing personal project, not a released game or an official publisher product.

## What's public

The [Projet40K repository](https://github.com/matheovitali/Projet40K) contains graphics and UI assets from the project. It does not contain the Unity source code or a playable build. I haven't published application screenshots or a demo yet.

Before sharing more of the project, I need to check the third-party artwork, licenses and repository history. The project is unofficial and has no affiliation with a game publisher.
